Two names, one object

a and b are two ways to reach the same object. Changing it through either name changes what both names see.

Step by step

let a = { status: "pass" };

let b = a;
b.status = "fail";

console.log(b.status); // "fail"
console.log(a.status); // "fail"
  1. let a = { status: "pass" } creates one object and makes a refer to it.
  2. let b = a copies the reference - the way to find the object - not the object itself.
  3. b.status = "fail" changes the shared object's status.
  4. Both logs show "fail" because a and b reach that same object.

Think of a and b as two labels pointing to the same box. If you change what's inside using either label, the change is visible through the other one too.

For this simple object, let b = { ...a }; creates a separate shallow copy. Then changing b.status does not change a.status.
